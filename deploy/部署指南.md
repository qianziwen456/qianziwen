# 千字文学习 App - 云端部署指南

## 📋 方案概览

你的 App 本质上是一个**静态网站**（HTML + CSS + JS），Python 只是用来提供文件服务。
所有学习数据都保存在浏览器本地（localStorage），不需要数据库。

因此有两种部署方式：

| 方案 | 难度 | 费用 | 适合人群 |
|------|------|------|----------|
| **A. 云服务器** | ⭐⭐⭐ | ~30-100元/月 | 想要完全控制、有自己的服务器 |
| **B. 静态托管** | ⭐ | 免费或极便宜 | 想要最简单、不想折腾 |

---

## 🅰️ 方案 A：云服务器部署（你选择的方案）

### 第一步：购买云服务器

推荐选择**轻量应用服务器**（便宜、够用）：

| 服务商 | 推荐配置 | 参考价格 |
|--------|----------|----------|
| 腾讯云轻量 | 2核2G | ~50元/月 |
| 阿里云轻量 | 2核2G | ~60元/月 |
| 华为云 | 2核2G | ~50元/月 |

**系统选择**：Ubuntu 22.04 或 CentOS 7/8

> 💡 新用户通常有优惠，首年可能只要几十块钱。

### 第二步：开放端口

在云服务商控制台的**安全组/防火墙**中，开放 **8001 端口**（入方向，TCP 协议）。

### 第三步：上传文件

把整个 `千字文学习` 文件夹上传到服务器。

**方法1：用 FTP 工具（推荐新手）**
- 下载 FileZilla 或 WinSCP
- 连接服务器（IP + 账号密码）
- 把文件夹传到 `/root/` 目录下

**方法2：用命令行**
```bash
# 在本地电脑执行
scp -r 千字文学习 root@你的服务器IP:/root/
```

### 第四步：运行部署脚本

登录服务器（用 SSH 工具如 PuTTY、Xshell，或直接在云控制台的网页终端），执行：

```bash
cd /root/千字文学习/deploy
bash deploy.sh
```

脚本会自动完成：
- ✅ 检查/安装 Python3
- ✅ 复制文件到 /opt/qianziwen
- ✅ 配置开机自启服务
- ✅ 开放防火墙端口
- ✅ 启动服务

### 第五步：访问

部署完成后，脚本会显示访问地址，类似：
```
http://你的服务器IP:8001
```

在浏览器打开即可使用！

### 常用管理命令

```bash
# 查看服务状态
systemctl status qianziwen

# 查看运行日志
journalctl -u qianziwen -f

# 重启服务（更新代码后）
systemctl restart qianziwen

# 停止服务
systemctl stop qianziwen
```

### 更新代码

修改了代码后，重新上传文件，然后：
```bash
cp -r /root/千字文学习/* /opt/qianziwen/
systemctl restart qianziwen
```

## 🅱️ 方案 B：静态托管（更简单，推荐先试这个）

由于 App 是纯静态的，可以直接部署到免费的静态托管平台，**不需要买服务器**。

### 方法1：GitHub Pages（免费）

1. 注册 GitHub 账号
2. 创建一个仓库（比如叫 qianziwen）
3. 把 `千字文学习` 文件夹里的所有文件上传到仓库
4. 仓库设置 → Pages → 选择 main 分支 → Save
5. 等待几分钟，访问 `https://你的用户名.github.io/qianziwen/`

### 方法2：Vercel / Netlify（免费，国内访问可能慢）

1. 注册 Vercel 或 Netlify 账号
2. 上传文件夹
3. 一键部署，获得一个网址

### 方法3：阿里云 OSS / 腾讯云 COS（国内访问快）

1. 开通对象存储服务
2. 创建存储桶，设置为「公共读」
3. 上传所有文件
4. 开启「静态网站托管」
5. 获得访问域名

> ⚠️ 注意：静态托管方案需要把 `index.html` 里的路径从 `/static/...` 改成相对路径 `static/...`（去掉开头的斜杠）。如果需要我帮你改，告诉我一声。

## 🔧 常见问题

**Q：访问不了怎么办？**
- 检查云服务器安全组是否开放了 8001 端口
- 检查服务器防火墙：`systemctl status firewalld`
- 检查服务是否运行：`systemctl status qianziwen`

**Q：手机能访问吗？**
- 能！任何能上网的设备（手机、平板、电脑）都可以通过网址访问

**Q：学习进度会保存吗？**
- 会的，进度保存在浏览器本地。换设备或换浏览器需要重新学习
- 不同设备之间的进度不互通

**Q：可以绑定域名吗？**
- 可以，买个域名（如 qianziwen.com），解析到服务器 IP 即可
- 还可以配置 Nginx + HTTPS，用 80/443 端口访问
